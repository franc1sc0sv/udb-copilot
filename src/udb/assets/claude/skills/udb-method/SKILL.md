# /udb-method

1. Launch the `methodist` subagent.
2. Find the example the teacher solved, in the slides and in the recording.
3. Copy the steps, in order, with the teacher's words. One citation per step.
4. Sources disagree: `status: conflict` and **ask the student**.
5. Never add or drop a step. Template: `udb method new <SUBJECT> <slug>`.
